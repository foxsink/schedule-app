# План разработки Telegram бота учёта расписания

## Контекст

Разработка с нуля Telegram бота для учёта рабочего времени сотрудников. Бот имеет три роли: сотрудник, админ, суперадмин (скрытая роль). Функции: учёт времени, расчёт зарплаты, экспорт в Excel, аудит-лог всех изменений.

**Стек:** Node.js + Telegraf + PostgreSQL + Prisma + Docker
**Часовой пояс:** UTC+7 (Новосибирск), фиксированный
**Язык интерфейса:** Русский
**Масштаб:** 20–100 сотрудников, несколько админов
**Режим работы:** Polling/Webhook, переключение через `BOT_MODE`

## Роли

| Роль | Видимость | Доступ |
|---|---|---|
| **EMPLOYEE** | Видна всем | Отмечать рабочие события, просматривать **свой** график (без финансов) |
| **ADMIN** | Видна всем | + управление сотрудниками, расписания, отчёты, зарплаты, премии/штрафы, Excel |
| **SUPER_ADMIN** | Скрыта (выглядит как ADMIN) | + просмотр единого аудит-лога (кто что менял). Задаётся через env |

## Расчёт зарплаты

```
За каждый день:
  ставка = EmployeeRate где effectiveFrom <= date (последняя)
  часы = (WORK_END - WORK_START) - обед - отлучки
  начислено = часы × ставка

За период:
  зарплата = Σ(начислено за день) + Σ(премии) - Σ(штрафы)
  больничные = 0 часов (не оплачиваются)
```
