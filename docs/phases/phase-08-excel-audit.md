# Этап 8: Экспорт в Excel + Аудит-лог

## Цель
Админ экспортирует зарплатную ведомость в Excel. Суперадмин просматривает аудит-лог.

## Файлы

| Файл | Описание |
|---|---|
| `src/services/excel.service.ts` | Генерация .xlsx: лист "Зарплаты" (сотрудник, часы, ставка, начислено, премии, штрафы, итого), лист "Детализация" (по дням) |
| `src/scenes/admin/export.wizard.ts` | Wizard: выбор периода → генерация → отправка файла |
| `src/scenes/admin/audit.scene.ts` | Только SUPER_ADMIN: список последних изменений, фильтр по дате/сотруднику/типу сущности |

## Формат Excel
### Лист "Зарплаты"
| Сотрудник | Часы | Ставка (руб/ч) | Начислено | Премии | Штрафы | Итого |
|---|---|---|---|---|---|---|
| Иванов Иван | 160.5 | 500 | 80,250 | 5,000 | 0 | 85,250 |

### Лист "Детализация"
| Дата | Сотрудник | Начало | Конец | Обед | Отлучки | Часы | Ставка | Сумма |
|---|---|---|---|---|---|---|---|---|

## Формат аудит-лога
```
🔍 Аудит-лог

24.02.2026 15:30 | Админов Админ
  ✏️ Изменение TIME_ENTRY #42
  Было: 09:00 WORK_START
  Стало: 08:45 WORK_START

24.02.2026 16:00 | Админов Админ
  ➕ Создание SALARY_ADJUSTMENT #5
  Премия 5000₽ для Иванов Иван: "За переработку"
```

## Критерии проверки
- Excel содержит корректные данные за период
- Файл отправляется в чат как документ
- Суперадмин видит аудит-лог с фильтрацией
- Обычный админ НЕ видит кнопку аудита
