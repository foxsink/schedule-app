# Этап 5: Админ — Просмотр расписания и отчёты

## Цель
Админ видит расписание всех сотрудников на сегодня и может строить отчёты за произвольный период.

## Файлы

| Файл | Описание |
|---|---|
| `src/middleware/adminGuard.ts` | Проверка роли ADMIN/SUPER_ADMIN |
| `src/services/report.service.ts` | `getDaySchedule(date)`, `getPeriodReport(employeeId?, from, to)` — агрегация часов за день/период |
| `src/scenes/admin/menu.scene.ts` | Главное меню админа: Расписание, Отчёты, Сотрудники, Зарплаты, Экспорт, [Аудит для SUPER_ADMIN] |
| `src/scenes/admin/schedule.scene.ts` | Расписание на сегодня: список сотрудников со статусами (работает / обед / отлучка / завершил / не начинал) |
| `src/scenes/admin/report.wizard.ts` | Wizard: выбор сотрудника (или все) → период → отчёт с часами |
| `src/keyboards/admin.keyboard.ts` | Клавиатуры для админского меню |

## Формат расписания на сегодня
```
📋 Расписание на 24.02.2026

🟢 Иванов Иван — работает (с 09:00)
🍽 Петров Пётр — обед (с 13:15)
🔴 Сидоров Сидор — не начинал
✅ Козлов Козёл — завершил (09:00–18:00, 8ч)
🏥 Новиков Нови — больничный
```

## Критерии проверки
- Расписание на сегодня показывает всех активных сотрудников
- Отчёт за период: часы по дням для одного/всех сотрудников
- Не-админы не могут получить доступ
