# Этап 9: Связывание сцен и навигация

## Цель
Все сцены зарегистрированы, навигация работает гладко, ошибки обрабатываются.

## Задачи

1. **Регистрация всех сцен в Stage** — bot.ts подключает все сцены
2. **Команды:**
   - `/start` — авторизация или переход в меню
   - `/menu` — возврат в главное меню (сотрудник или админ в зависимости от роли)
   - `/cancel` — выход из текущей сцены → главное меню
3. **Кнопки "Назад"** — в каждом wizard/scene возврат на предыдущий шаг или в меню
4. **Переключение режимов** — админ может переключаться между админским и сотрудническим меню (т.к. админ тоже может отмечать время)
5. **Обработка ошибок:**
   - `bot.catch` — логирование + сообщение пользователю
   - `answerCbQuery` — ответ на каждый callback чтобы убрать "часики"
   - Неизвестные команды/сообщения — подсказка
6. **Обработка edge cases:**
   - Пользователь без авторизации пытается нажимать кнопки → сообщение "Используйте /start"
   - Истёкшая сессия → переход на /start

## Критерии проверки
- Навигация между всеми сценами работает без ошибок
- /cancel всегда возвращает в меню
- Админ может переключаться между ролями
- Нет "зависших" состояний
