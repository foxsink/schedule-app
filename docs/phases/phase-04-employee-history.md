# Этап 4: Просмотр графика сотрудником

## Цель
Сотрудник просматривает свои записи за выбранный период. Без финансовой информации.

## Файлы

| Файл | Описание |
|---|---|
| `src/scenes/employee/history.scene.ts` | Wizard: выбор периода (сегодня / эта неделя / этот месяц / ввести даты) → показать записи |

## Формат вывода
```
📅 24.02.2026 (Вт)
  09:00 — Начало дня
  13:00 — Обед
  14:00 — Конец обеда
  16:30 — Отлучка
  17:00 — Возврат
  18:00 — Конец дня
  Итого: 7ч 30м

📅 25.02.2026 (Ср)
  🏥 Больничный
```

## Критерии проверки
- Сотрудник видит свой график за неделю
- Зарплата/ставка НЕ отображается
- Пагинация при большом количестве записей
