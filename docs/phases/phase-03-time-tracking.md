# Этап 3: Учёт времени сотрудника

## Цель
Сотрудник через inline-кнопки отмечает рабочие события. Меню контекстное: показываются только доступные действия в зависимости от текущего состояния.

## Логика состояний

```
Нет записей за сегодня → [Начать день] [Больничный]
После WORK_START       → [Обед] [Отлучка] [Закончить день]
После LUNCH_START      → [Конец обеда]
После PERSONAL_LEAVE_START → [Вернулся]
После WORK_END         → "День завершён ✓"
После SICK_LEAVE       → "Больничный ✓"
```

## Валидация
- Нельзя начать день дважды
- Нельзя уйти на обед если не начал день
- Нельзя закончить обед если не начинал
- Больничный только если нет записей за сегодня
- Множественные отлучки за день разрешены

## Критерии проверки
- Полный рабочий день: начало → обед → конец обеда → отлучка → возврат → конец дня
- Больничный на чистый день
- Попытка некорректного действия отклоняется
